# server.js: the cut

Which stream owns each file now is [docs/BUILD.md](../../docs/BUILD.md), and what the shared shapes are is
[model/README.md](model/README.md). This file keeps only the record of the original split: `server.js` was cut
into modules by area with no behaviour change, and the replay harness passed 22 of 22 on the split as on the
original. Several modules named below have since been removed by the design rulings (R2, R3, R4, R9: `linker.js`,
`triage.js`, `resolve.js`, `things.js`, `state.js`, `audit.js`, `sourceref.js`, `tools-queries.js`,
`routes-discovery.js`), and the cut below is history, not the current layout.
